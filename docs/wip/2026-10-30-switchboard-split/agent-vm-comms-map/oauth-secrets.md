## Representative case and failure distinctions

source: Connecting one Gmail account starts from the owner index POST or the authenticated agent's begin action, returns a local authorization URL, binds the browser human to the ceremony, validates selected permission groups, shows Continue to Google, receives the code callback, and presents a separate local account confirmation before persisting tokens. Each selected application commits independently; successful applications remain complete while a remaining application can retry. (`packages/agent-vm/src/controller/oauth/oauth-account-policy-routes.ts:277-297`; `packages/oauth-broker/src/google/google-oauth-broker-service.ts:245-261,470-487,535-611`; `packages/agent-vm/src/controller/oauth/oauth-https-server.ts:549-610,699-719`)

source: A later configured CLI call names accountId in validated input; the host resolves the current agent profile/command classification, derives service/effect requirements and combines the compiled maximums, configured defaults, authenticated per-account overrides and provider scopes. Deny stops it, missing provider grant yields consent-required, ask needs exact-call approval, and allow proceeds without that approval. Approval cannot manufacture absent Google consent. (`packages/agent-vm/src/controller/oauth/google-permission-policy-service.ts:267-340,510-568`; `packages/tool-portal/src/google-account-policy.ts:31-70`; `packages/agent-vm/src/controller/control-session/gateway-control-controller-execution-authorization.ts:362-386`)

source: Credential freshness and dispatch authority are rechecked after asynchronous refresh/materialization. A generation, authorization metadata, credential ID or material revision mismatch returns unavailable/stale and creates no authorized dispatch; current Google policy binding is also compared immediately before command assignment. (`packages/oauth-broker/src/google/google-runtime-credential-policy.ts:111-160`; `packages/agent-vm/src/controller/runner/configured-cli-managed-vm-executor.ts:218-249,280-291`)

source: Refresh uses a 60-second early-refresh skew, a 30-second degraded retry gate, and exact-snapshot single flight. invalid_grant or changed scope set records reauthorization-required; transient/provider failure records degraded; successful refresh encrypts the new payload, retains the previous refresh token if no replacement arrives, advances material/provider revisions and performs CAS. (`packages/oauth-broker/src/google/google-credential-refresh-coordinator.ts:88-90,163-264,269-297`)

source: Local disconnect synchronously changes accessState to disconnecting, nulls credential/envelope/material fields and advances generations/revisions, then awaits matching runtime containment and settles disconnected. Other agent authorizations and provider consent remain unchanged. The adapter has revokeAuthorization, but the source disconnect flow does not call it; searched all broker Google sources for revokeAuthorization callers. (`packages/oauth-broker/src/oauth-catalog-repositories.ts:393-448`; `packages/oauth-broker/src/google/google-authorization-disconnect.ts:35-89`; `packages/agent-vm/src/controller/oauth/oauth-https-server.ts:392-409`; `packages/oauth-broker/src/google/google-oauth-adapter.ts:393-400`)

source: Database token payloads and account policy snapshots use XChaCha20-Poly1305 envelopes with a random per-payload DEK wrapped by the separately resolved KEK; authenticated binding includes zone, owner, provider account subject, agent, application and revisions. The entire SQLite file is not opaque: account metadata, lifecycle fields and policy/event metadata have explicit SQL columns. (`packages/oauth-broker/src/envelope-codec.ts:33-71,203-237`; `packages/oauth-broker/src/catalog-schema.ts:7-104`; `packages/agent-vm/src/controller/oauth/controller-oauth-runtime.ts:238-252`)

source: Secret source and delivery mode are independent axes. Environment source means host-side lookup, not raw guest delivery. Gateway audience may deliberately receive env values; Tool VM audience must use HTTP mediation, filtered by agentAccess before resolution. A credentialed configured CLI can instead use a finalized read-only credential-file mount; that is a different path from the Google dynamic OAuth token placeholder. (`packages/secret-management/src/composite-secret-resolver.ts:73-85`; `packages/gateway-lifecycle/src/split-resolved-gateway-secrets.ts:44-65`; `packages/agent-vm/src/tool-vm/tool-vm-lifecycle.ts:380-395`; `packages/agent-vm/src/controller/credentialed-runtime/credentialed-managed-vm.ts:55-90,126-165`)

source: Host workspace Git token resolution is separate from zone VM secrets and has an environment fallback when no explicit host token configuration exists. (`packages/agent-vm/src/controller/controller-runtime-support.ts:31-55`)

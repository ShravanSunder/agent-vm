(agent-portal-sdk/src/gateway-runtime-client/gateway-runtime-sandbox-operations.ts:132-170; agent-portal-sdk/src/contracts/sandbox-environment-contracts.ts:11-21)

## Delivery/lifecycle guarantees actually implemented

source: Control send checks current accepted session/socket both before admission and immediately before send, validates envelope/domain kind and operation and derived delivery policy, forbids bulk, waits for a 2-second admission receipt, then independently awaits a correlated command result. A receipt proves admission, not completion; send/result failures close the control session. (gateway-runtime/src/control-endpoint/gateway-control-application-message-runtime.ts:114-200)

source: Policies differ by semantic operation: readiness latest-wins; health append-only observation; create/reacquire/binding/use-start critical-idempotent; renew/use heartbeat/controller execution/attachment/approval reserve-arm-decide single-use-critical; get/peek/release/use-end/cancel acked-idempotent. Lease-create without idempotencyKey becomes single-use-critical. These constants select behavior but are not an exactly-once promise. (gateway-control-contracts/src/index.ts:1552-1603)

source: Controller dispatcher maintains bounded dedupe results (512 messages / 60 seconds contract), rejects expired replay windows, and runs specially prepared mutating operations through a semantic ledger; the domain handler prepares lease mutations and workspace Git push. This semantic authority is distinct from transport receipts or data-channel credit. (control-protocol-contracts/src/index.ts:25-32; agent-vm/src/controller/control-session/control-session-dispatcher.ts:139-163,258-295; agent-vm/src/controller/control-session/gateway-control-domain-handler.ts:1593-1654)

source: Control hello requires matching controller/gateway/process/domain/peer/version and strictly increasing attachment generation; accepted replacement resets session state, creates fresh connection/session IDs and disconnects the superseded socket. Signed ready proofs and upgrade credentials are individually consumed; replay, expiry and identity/signature mismatch reject. (gateway-runtime/src/control-endpoint/gateway-control-session-service.ts:321-385,467-509)

source: Sequence helper drops old/non-advancing messages, accepts lossy advisory latest/droppable without advancing strict sequence, and marks a gap stale for authoritative continuity. This is per-envelope ordering/fencing, not durable task replay. (control-protocol-contracts/src/index.ts:485-519)

source: Separate execution data-channel implementation enforces full binding equality, strict next sequence, exact current credit, queue byte capacity and terminal EOF/cancel; transport close is ambiguous and every exposed state says redispatchAllowed:false. Its upgrade authentication is supplied by caller, so its mere existence does not implement a new remote computer authorization model. (gateway-runtime/src/controller-execution/controller-execution-data-channel.ts:93-119,197-236,239-310; gateway-runtime/src/controller-execution/controller-execution-websocket-server.ts:20-27,75-105)

source: Production runtime retirement stops heartbeat, retires UDS, retires lease binding/runtime/process groups, unsubscribes attachment, flushes evidence/control/heartbeat, closes control and provider, retires artifacts, and accumulates failure codes. Those outcomes span computer execution, tool services and attachment lifecycle; relocation must preserve their owners/draining semantics. (gateway-runtime/src/production/gateway-runtime-production-lifecycle.ts:127-193; gateway-runtime/src/production/gateway-runtime-production-sandbox-dispatcher.ts:454-477)

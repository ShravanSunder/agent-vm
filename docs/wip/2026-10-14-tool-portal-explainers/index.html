The scope you asked for

Your original questions
├── Existing system: Tool Portal, MCP Portal and Gateway Runtime
├── Approval: package owner, shared implementation and agent integration
├── General reuse: a service usable beyond managed Hermes
├── Machine and VM access: authorized, configured, multi-machine
├── Harnesses: Hermes, Codex, Claude Code, Cursor, Pi; maybe OpenCode
├── Discovery: client-native search, compact Portal and code bindings
├── Language and hosting: TypeScript service versus Rust integration
└── Resilience: logical interaction separate from physical connection

The collection covers this whole tree. The portable-runtime view compares authority options without treating a recommendation as an accepted design.

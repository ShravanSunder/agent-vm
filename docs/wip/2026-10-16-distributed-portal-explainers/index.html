Two levels of MCP servers

Agents enter through Cloudflare MCP Portal. Our **cloud MCP gateway** connects to remote MCP providers and **computer MCP servers**. Each computer server composes Tool Portal with the tools and execution backends enabled for that computer. **Agent coordination is a separate MCP service**, potentially protected by Cloudflare too. The target topology

The cloud gateway is an MCP server to the agent and an MCP client to downstream services. A computer server is an MCP server to that gateway and may itself call local or remote providers. “Upstream” is relative to the caller; it does not name another mandatory deployment tier.

Present the caller's permitted catalog, resolve a stable tool target, enforce gateway admission and route the request. Bind the outer operation to any inner operation and preserve pending, failure and uncertain outcomes. Cloudflare authentication and gateway policy do not automatically supply permission to act on a computer. Serve this computer's configured capabilities, authenticate requests from the gateway and enforce the resource's limits before invoking its backends. Native actions and host processes run where their implementations live. Final local enforcement is the recommendation. Which authority requests and records an approval remains open. The coordination MCP has different interaction priorities and owns its own state and operations. Sharing Cloudflare protection or authentication code need not combine its service, endpoint, sessions or storage with the tool gateway. Its implementation is outside this work.

Mac and cloud are host compositions

Starts the generic gateway and portal; wires a Node HTTP listener, configured connectors, a protected secret resolver and an authority/storage adapter. A tunnel can carry remote requests to its loopback listener. Native actions still need a configured local backend. The portal does not acquire machine-wide authority merely by running on the Mac. Starts the same generic gateway/portal behavior through a Worker request entry; wires protected bindings, HTTP dispatch and the selected durable authority adapter. Cloudflare MCP Portal can register this endpoint as an upstream. The Worker calls remote tools; host placement does not grant native Mac execution. One package can supply both host runners. Several processes can serve one authority if its state contract supports that. Two hosts using the same package may instead be independent authorities. Neither case follows from an import statement.
